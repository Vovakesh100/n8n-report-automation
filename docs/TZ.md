# ТЗ: n8n-report-automation

## Цель
Автоматический ежедневный отчёт по продажам из CSV-файла, который отправляется в Telegram. Учебный портфолио-проект (demo), не клиентская работа.

## Пользователь
Владелец небольшого магазина, который хочет получать сводку по продажам за день без ручной работы.

## Вход и выход
- Вход: CSV-файл с колонками `date,product,quantity,unit_price_cents`.
- Выход: сообщение в Telegram со сводкой по каждой дате: выручка, количество заказов, самый продаваемый товар.

## MVP
1. Python-функция, которая считает сводку по строкам (без I/O).
2. CLI, который читает CSV и печатает сводку в JSON.
3. n8n-workflow: читает CSV, вызывает CLI, отправляет результат в Telegram.
4. Запуск workflow вручную; расписание добавляется после ответов на вопросы.

## Не делаем
Подключение к кассам, базам данных или API магазинов, графики, несколько магазинов, облачный хостинг.

## Критерии приёмки
1. Все суммы хранятся в целых центах, без float (тесты).
2. Сводка за пустой день корректна (тест).
3. CLI выдаёт валидный JSON для тестового файла (тест).
4. В репозитории нет токенов, ключей и реальных данных (проверка тестировщиком).
5. Workflow импортируется в n8n без ошибок, а все секреты заменены плейсхолдерами.
